Novo local

É o endereço do computador que grava (aparece em Ajustes → Este local), não o da câmera.

Instalar câmeras

As câmeras gravam num computador ligado no local (com o programa Minhas Câmeras aberto). Conecte este celular no Wi-Fi do local onde vai instalar.

Não encontrei o computador neste Wi-Fi.
  • O celular está no Wi-Fi do local (não no 4G)?
  • O computador está ligado, com a janela Minhas Câmeras aberta?
  • Ainda não tem o programa no computador? Peça para quem cuida das câmeras instalar (instruções em github.com/sonyhelthon/cameras-app).
